# LaptopKeyboardTool
一键禁用/恢复笔记本内置键盘，打游戏不再怕误触 🎮

📌 简介
轻量级工具，专门解决外接键盘时笔记本自带键盘误触的问题。

✨ 功能
方案1 (Pnputil)：精准禁用板载键盘 ⭐推荐
方案2 (注册表)：禁用全部PS/2设备

🔧 环境
项目	要求
框架	.NET Framework 4.0
系统	Windows11 （其它未测试）
设备	ACPI\MSFT0001 板载键盘

📦 使用
解压后以管理员身份运行 LaptopKeyboardTool.exe

⚠️ 禁用/恢复操作需重启生效，请备好外接键盘或屏幕键盘

🛠️ 编译
推荐Visual Studio 2017及以上
